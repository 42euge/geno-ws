# geno-ws — DEPRECATED

[![Docs](https://img.shields.io/badge/docs-GitHub%20Pages-blue)](https://42euge.github.io/geno-ws/)

> **⚠️ Deprecated — use [geno-tt](https://github.com/42euge/geno-tt) instead.**
> Workspaces now follow the code-org scheme
> `~/code/<track>/<domain>/<workspace>.<born>/<repo>` and are managed by the
> `tt` CLI (`tt new-project`, `tt ecosystem-clone`, `tt overlay`, `tt migrate`).
> `geno-ws` is retained only to migrate existing color-folder workspaces.

Part of the [geno ecosystem](https://github.com/42euge/geno-tools).
